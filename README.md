# tgdl

自用的 Telegram 媒体批量下载器：一个 Windows exe，双击后在浏览器里操作。支持下载开启了"限制保存内容"的频道和群，前提是你已经加入。

- **单个 exe**：不用装 Python、tdl、浏览器插件或 Telegram Desktop。
- **扫码登录**：用手机 Telegram 扫码即可，也支持手机号加验证码，以及两步验证密码。
- **浏览 + 勾选 + 批量下载**：左边是聊天列表，右边是带缩略图的视频/图片网格。可以单选、按住 Shift 连选、全选，也能一键下载整个聊天的全部视频。
- **下载引擎是 [tdl](https://github.com/iyear/tdl) 的 core 模块**：多连接分片、同时下载多个文件。下载前会重新读取消息，避免文件引用过期导致失败。
- **数据只在本机**：程序只连接 Telegram 官方服务器；登录凭证、配置、日志都放在 exe 旁边的 `tgdl-data` 文件夹里。

## 使用

1. 从仓库的 Actions 页面，打开最新一次成功的 build，下载 `tgdl-windows-amd64` 附件，解压得到 `tgdl.exe`。
2. 把 `tgdl.exe` 放进一个普通文件夹（不要放在 Program Files），双击运行。
   - exe 没有数字签名，Windows 可能提示"Windows 已保护你的电脑"：点「更多信息」→「仍要运行」。
3. 浏览器会自动打开 `http://127.0.0.1:17800/`。第一次需要登录：手机 Telegram →「设置 → 设备 → 连接桌面设备」，扫描页面上的二维码。
4. 左边选聊天，上面切换「视频 / 图片和视频 / 图片 / 文件」，勾选后点「下载所选」，或者点「下载全部视频」。
5. 右上角「下载任务」可以看进度、取消、重试失败的文件、「重新开始」整个任务、打开文件夹。

已经下载过的文件在网格里带「已下载」标记，「全选未下载」可以只选还没下的。

**筛选**：按文件大小（MB）和视频时长（分钟）筛选，只显示符合条件的文件；「全选」「下载全部」也只针对符合条件的。

**预览**：卡片左下角「▶ 预览」可以在线播放视频、看原图，支持拖动进度条（边下边播，不用等整个文件下完）。弹窗里可以上一个/下一个（键盘左右键）、选择、单独下载。MKV、HEVC 等浏览器不支持的格式播不了，需要下载后用本地播放器看。

文件保存在 `下载目录\聊天名\` 下，文件名是 `消息ID_原文件名`。没有原文件名的视频，会用说明文字的第一行命名。已经下载过的文件（同名同大小）会自动跳过。

**断线和中断**：连接断开时会自动重连重试；一批结束后，失败的文件会再自动重试一轮。任务列表保存在 `tgdl-data\jobs.json`，关掉程序再打开，未完成的任务显示为「已中断」，点「重新开始」就会接着下。

**日志**：`tgdl-data\tgdl.log` 记录每个任务的开始、结束汇总，以及每个失败文件的消息 ID 和原因（不含消息内容）。

**升级**：先退出程序，用新的 `tgdl.exe` 覆盖旧的，`tgdl-data` 文件夹保持不动，就不用重新登录。

**关闭黑色的命令行窗口，或点页面上的「退出程序」，就会退出。**

## 设置

点页面右上角「设置」修改，保存在 `tgdl-data\config.json`：

| 项 | 默认 | 说明 |
|---|---|---|
| 下载目录 | `下载\tgdl` | 每个聊天一个子文件夹 |
| 单文件线程数 | 4 | 下载一个文件时开几个连接 |
| 同时下载文件数 | 2 | 调大更快，但更容易被 Telegram 限流 |
| 代理 | 空 | 只支持 `socks5://主机:端口`，改完重启生效 |
| 本地端口 | 17800 | 改完重启生效 |
| api_id / api_hash | 空 | 见下文 |

## 需要知道的

- **登录凭证**：`tgdl-data\session.json` 就是你的 Telegram 登录凭证，拿到它等于登录了你的账号，不要发给别人。页面上「退出登录」会让这个会话在 Telegram 端失效，并删除该文件。
- **API ID**：默认用 Telegram Desktop 的公开 API ID 登录，和 `tdl login` 一样。严格来说 Telegram 的 API 条款要求第三方客户端用自己的 ID，所以有一定封号风险。更稳妥的做法是在 [my.telegram.org](https://my.telegram.org) 申请自己的 api_id / api_hash，填进设置，重启后重新登录。
- **限流**：大批量下载可能触发 Telegram 限流，程序会自动等待；等待超过 10 分钟的请求会作为失败显示，稍后点「重试失败的」即可。想更安全可以用小号。
- **付费媒体**（Stars）没买的话，服务器不会给文件，下载不了。

## 安全

- 本地网页只监听 `127.0.0.1`，并拦截来自其他网站的请求（校验 Host 和 `Sec-Fetch-Site`，API 请求必须带自定义请求头）。
- 依赖固定版本，`go.sum` 由 Go 官方校验数据库验证。每次 CI 都会运行 `go mod verify` 和 `govulncheck`。GitHub Actions 固定到提交哈希。
- 集成前审查过 tdl core v0.20.4 的全部源码，以及 gotd 和其他依赖：没有发现恶意代码、遥测或对非 Telegram 服务器的访问。
  - gotd v0.140.0 有一个已知漏洞（GHSA-whmm-qj9r-wvr2），这里用的是已修复的 v0.161.0。
  - tdl core 里会关闭代理 TLS 校验的 `netutil` 包没有被引用；代理用 `golang.org/x/net/proxy` 实现。

## 开发

```
go test ./...
go build -trimpath -o tgdl.exe .
```

代码结构：
- `internal/tgc`：Telegram 客户端（连接、登录、聊天、媒体列表、缩略图）
- `internal/jobs`：下载队列，接 tdl core 的下载器
- `internal/web`：本地网页和 API（界面文件在 `static/`）

下载引擎来自 tdl（AGPL-3.0）。本项目仅供个人使用；如果要分发，需要遵守 AGPL-3.0。
